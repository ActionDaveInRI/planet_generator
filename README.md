# Planet generator

Build Earthlike worlds with procedural terrain, starfields, and several rendering experiments.

[Open project](https://actiondaveinri.github.io/planet_generator/) · [All projects](https://actiondaveinri.github.io/spaceship/) · [Versions](https://actiondaveinri.github.io/planet_generator/versions.html)

The repository root is this project’s directory. Current build: `index.html`; earlier builds: `versions/`. Original launch URLs redirect to their versions. Requires WebGL and external graphics modules. Some historical module URLs may need repair; runtime behavior is unchanged. Screenshot pending.
